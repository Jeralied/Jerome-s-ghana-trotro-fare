#  Ghana Trotro Fare Calculator

A simple and responsive web application that helps commuters estimate trotro fares between selected locations in Accra, Ghana.

## Features

- Fast fare estimation
- Clean and responsive interface
- Travel time estimation
- Easy-to-use dropdown menus
- Mobile-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Feedback

Tested with 4 GCTU students across multiple routes (Circle-Kaneshie, Circle-Lapaz, Tudu-Makola, Accra Mall-Kaneshie). All confirmed the fares matched what they'd normally expect to pay, and the interface needed no explanation to use. No issues or confusing points were reported

## Future Improvements

- Add more routes across Ghana
- Dark mode
- Fare updates based on transport unions
- Google Maps integration
- Search functionality
